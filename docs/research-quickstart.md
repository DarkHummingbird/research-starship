# 科研星舰：普通用户使用说明

## 安装与第一次启动

macOS 下双击项目中的 `install_research.command`。安装程序会先准备独立运行环境，**安装完成后**才进入服务商配置向导。

配置向导支持 Kimi、DeepSeek、Qwen 和 OpenAI 兼容服务。API Key 输入时不会显示，配置保存在本机“运行数据/配置”目录，不应复制到聊天或提交到源码仓库。

普通资料默认使用已配置的在线 API。**本地保密模式默认关闭**，普通使用不需要下载或加载本地模型。需要处理 **L3 保密资料**时，在“数据与隐私 → 模型与隐私中心”中主动开启本地保密模式，并按安装说明准备本地生成、向量化和文字识别组件；只有开关已开启且本地生成模型就绪后，界面才开放 L3 和本地生成。该设置按账号保存，账号之间互不影响。L3 本地组件不可用时，相关分析会暂停，不会改用在线服务。

启动：

```bash
./start_research.sh
```

在线检索可在 `providers.env` 同目录放置不含密钥的 `qwen-rag.json`，通过 `embedding_tasks.memory_embed` 和 `rerank_tasks.memory_rerank` 指向 Qwen 模型；启动脚本会在未显式设置 `LLM_CONFIG_FILE` 时自动加载。百炼 Key 只写入 `providers.env` 的 `DASHSCOPE_API_KEY`，不要写入 JSON。Qwen Embedding 当前按每批最多 20 条发送，Rerank 使用百炼 `/reranks` 接口。更换 Embedding 模型后需要重建索引，不同模型的向量不会混用。

## 科研星舰与助手

顶部的“助手”入口保留普通文本处理、个人偏好、提醒和公开网页搜索等已有能力。个人偏好与科研资料分开保存，不会混入课题检索。

## 公开网页搜索与读取

在助手聊天中输入公开网址并要求读取，或要求搜索公开信息即可。已配置 DeepSeek 时，可使用官方 Search/Fetch 服务；这两项服务按成功请求计费，失败或空结果按服务商规则处理。仍支持管理员配置 SearXNG 或 Jina 作为其他后端。

网页内容属于不可信资料，不能改变系统规则或授权其他操作。不要输入内网、 localhost、登录后页面或包含账号密码的网址。

某些受管网络会把公网域名映射到保留地址。管理员可在本机服务商配置中设置 `CRAWL_DNS_ALLOWLIST`，只放行该网络实际使用的 CIDR 网段；默认不放行，直接输入内网 IP 仍会被拒绝。系统证书信任由 `truststore` 提供，不应通过关闭证书校验解决读取失败。

## 普通对话中的图片和文件

普通助手输入框左侧的回形针可添加一个附件，用于当前这次对话。支持 JPG、PNG、WebP 图片，以及 PDF、DOCX、Markdown 文档。图片不超过 10 MiB，文档不超过 20 MiB，解析后的文档最多 100 个片段。

- 默认仅本次对话使用，不自动进入个人记忆或科研资料库，也不参与正式科研检索。
- 内部资料默认仅本机处理；如要使用在线模型，需要主动勾选外发许可。许可覆盖该附件、解析片段和本条消息，模型配置变化后需要重新上传确认。
- L1/L2 图片可使用 DeepSeek `deepseek-flash` 视觉理解，文档由在线模型读取按问题选出的片段；DeepSeek 调用按服务商规则计费。
- L3 只能本机处理：图片使用 OCR 提取文字，再交给本地模型。当前不等于理解图表、颜色或视觉布局，OCR 未识别到文字时会明确失败。
- 附件只绑定第一次使用的会话，不能转给其他账号或其他会话。外部调用失败不自动重发。
- 一次性附件保留 7 天，访问附件功能时会清理已到期内容；也可以提前点击附件卡片上的 × 删除。删除会清除正文和派生内容。

普通对话仍然允许写作、改写、润色或根据附件创作，不另设科研论文写作入口。需要长期保存和可信检索时，应改在科研资料库上传并完成审核；当前普通附件不会自动转存。

科研星舰保持五个工作区：

- **课题首页**：优先显示当前最值得执行的一步，并提供直接操作入口；核心问题、当前基线和实验保持可编辑，结论、未解决问题、证据缺口、术语等放在按需展开的详情中。
- **资料库**：上传资料，查看原文、核心内容和来源。“添加资料”分别提供 arXiv 论文导入与 GitHub 仓库导入；论文按 ID/版本和章节处理，仓库按固定 commit 和文件路径处理，不共用解析方式。
- **待我确认**：显示待确认资料及数量，集中处理异常字段、待审核笔记和关联状态复核。
- **课题问答**：基于当前课题已确认的资料提问，进行跨文献综合，也可以使用研究辅助。
- **数据与隐私**：在模型与隐私中心集中查看在线模型、L1/L2/L3 规则、本地开关及组件状态，或处理轻量导出、历史版本、撤销、冲突和回收站。组件检测只检查文件，不启动模型。

## 课题状态与实验复盘

1. 首页会区分“系统正在处理”“需要人工确认或处理”和“可以继续研究”，并给出对应操作入口。在“课题首页”填写当前核心问题和下一步建议，点击“保存研究状态”。下次打开该课题可继续查看。
2. “添加课题条目”支持未解决问题、证据缺口、待办和术语。术语可分别填写全称、缩写、定义或备注。条目可标记已解决、重新打开或归档；带来源的废弃条目即使来源已删除也可归档，历史来源快照仍保留。
3. 已确认的课题笔记会显示在“已确认结论”；AI 综合必须先保存为待确认笔记，再由用户审核，不会因为生成回答就自动成为结论。
4. 在课题问答中输入问题后，可点击“将当前问题加入未解决问题”。
5. 新建实验卡片时可填写假设、变量、对照、数据版本、代码版本和下一步。新卡片始终是“设想”，系统不执行实验，也不会自动生成实验结果。
6. 完成实验后，由用户回填结果、失败原因和下一步，并主动修改状态。状态和结果不会被系统用来虚构已执行实验，也不会自动替换当前基线。
7. 来源版本变化、取消确认或删除后，相关笔记退出正式检索，绑定来源的状态条目和实验进入复核。实验结果不会被删除，当前基线仍保留并显示待复核，不会被自动替换。来源更新后须先重新确认资料，再核对实验或基线的引文；确认复核后，实验恢复原先状态。无法唯一定位引文时须重新选择来源，不能直接恢复。新增相关资料只创建核对通知，不自动判定冲突或改写原结论；词项提示不能保证发现全部语义关联。
8. 实验卡片展开后可核对和编辑假设、变量、对照、数据/代码版本、结果、失败原因、下一步及结果来源。

## 跨文献综合

1. 在“课题问答”展开“跨文献综合”，选择当前课题中 **2–5 份不重复且已确认**的资料。
2. 默认“结构化比较”不调用模型，按方法、数据集、指标和局限整理已有分析。普通教程等没有结构化分析的资料，会保留各原文片段供后续归纳，不假装已有指标。
3. 可切换“在线综合回答”，选择已经配置的模型。L2 会先显示实际片段、服务商和用途供审批；L3 不允许在线综合。外部调用失败不会自动重发或切换到本地模型。
4. 数据集、指标单位或条件不一致时，系统提示可比性限制。缺失内容保持待核验，不直接进行数值排名。
5. 综合目标用于记录研究问题，比较字段包括方法、基线、数据集、指标、实验条件和局限。综合来源表可查看逐字引文、尝试原文高亮或打开原文。
6. 每份资料最多选取 12 条、6000 字符，全部资料最多 30000 字符，综合目标最多 2000 字符。系统按字段和章节轮转选取，并显示实际覆盖范围及截断说明；未选内容不会发给模型。没有有效来源片段时会明确失败，不会改用无来源回答。
7. 结构化表格或在线回答均可点击“保存为待确认课题笔记”。笔记保留资料版本、章节、片段和逐字引文，确认前不参与正式检索。重复点击或并发保存同一综合只会创建一份笔记；在线返回及保存前会重新核对来源，发生变化时须重新生成。

## 导入与核对

1. 新建课题，只需填写名称；研究目标可后补。
2. 在“资料库”上传资料。系统默认按论文处理并自动拆分，高级设置通常不用修改。
3. 选择保密程度：
   - 公开资料：可使用已经启用的外部资料服务。
   - 内部资料：在线处理前需要确认实际发送范围。
   - 保密资料：只在本机处理。
4. 上传后自动读取和分析。论文结构化分析默认使用已配置的在线模型，L3 自动使用本地通道。论文分析、在线向量索引或候选重排涉及 L2 内容时，会先展示外发审批；审批绑定资料版本、片段、模型和用途，变化后需重新审批。在线失败不会自动切换本地模型。
5. 扫描 PDF 可选择“DeepSeek 在线文字识别”或“本地文字识别”。在线 OCR 使用 DeepSeek 独立 OCR API 的 `text_recognition`，按页返回文字和坐标，不把识别结果交给对话模型；L1 可直接执行，L2 须先审批整份原始 PDF，L3 禁止在线 OCR。输出达到长度上限的页面会明确标为不完整，必须对照原文处理。
6. 默认优先核对异常字段。无异常内容可在预览后确认，但仍需用户主动操作。
6. 只有确认后的内容才进入正式课题知识和后续检索。

“原文”用于阅读原始内容，“来源”用于检查证据。解析结果和原始模型输出位于折叠的“诊断与原始输出”区域。

公式、表格和扫描页需要特别核对；文字识别置信度高也不代表公式符号一定正确。

## 来源定位

- 在论文详情中，左边查看原文，右边查看核心内容、待核对字段及课题问答。
- 对有来源的字段点击“在原文中定位”，可以在原页看到高亮。
- 高亮支持能在同一页唯一匹配的跨行引文，也支持新识别扫描件的文字行定位。
- 扫描件按识别行框高亮，可能包含同一行的其他文字；旧扫描件缺少坐标时需要重新导入并识别。
- 重复内容、缺少可靠坐标或资料版本变化时，请打开原文人工核对。高亮只生成临时预览，不修改原件。

## 提问与保存课题笔记

- 默认只检索当前课题已经确认的资料。需要跨课题时，展开“检索范围”并明确勾选。
- 已配置在线模型时，可优先选择在线生成回答；也可以选择原文摘录或本地生成。
- L3 问题和资料不会使用在线生成、在线 Embedding 或在线 Rerank。
- 点击来源可查看引文并尝试定位高亮；找不到依据时，系统应明确说“未找到可核验证据”。
- 明确的比较问题由本地规则识别；复杂问题可由在线 Query Planner 生成受约束的 JSON 查询计划。规划器只识别意图和比较对象，不生成事实或引文；L2 的查询规划与最终回答分别审批，L3 不调用在线规划。比较回答显示已覆盖和缺失的对象，缺失时不能据此完整排名。
- 在线查询 Embedding 和 Rerank 是可选增强。连接、超时、限流或服务端失败时不自动重试，可分别降级为 BM25 词语检索或已经计算的本地排序，并在结果中明确提示。鉴权或请求参数错误不会降级，L3 仍禁止在线增强。
- 同一方法对应多份资料，或用户只说“这两种方法”时，系统先展示候选标题、版本和方法，不自动猜测。用户选择 2–5 份已确认资料后才继续检索和审批；所选资料仍受当前账号与课题隔离约束。
- 回答或论文问答下方可展开“保存为课题笔记”，编辑需要长期保留的标题和内容，并选择来源事实、AI 归纳、实验设想或我的记录。
- 来源事实和 AI 归纳必须关联真实资料版本及逐字引文；无来源时只能作为我的记录或实验设想保存。
- 保存后笔记先进入“待我确认”，不会直接参与正式检索。
- 来源资料更新、取消确认或删除后，关联笔记会退出有效检索；重新确认时需要引文仍能在当前版本中唯一定位。

## 研究辅助

“课题问答”中的“研究辅助”默认折叠，默认使用在线模型，也可主动选择本地模型；L2 外发前需要审批，L3 会拒绝在线连接并引导使用本地保密模式。保留：

- 记忆对照和消融实验设想；
- 来源支持的对比表格；
- 帮助理解方法步骤的伪代码；
- 用于发现证据缺口的模拟审稿。

伪代码不代表已实现或复现成功，模拟审稿不等于正式审稿或录用预测。生成内容保留统一风险提示，仍需人工核对。

完整论文写作、局部 LaTeX 和个人风格模仿不属于当前 V1 界面范围。助手中的普通写作、润色和翻译仍可使用。

## 引用元数据核验

项目级 `research-rag` Skill 用于检索与生成分别诊断、比较覆盖检查和验收。引用元数据也可通过 `POST /api/research/projects/{project_id}/citations/verify` 核验，支持 DOI、标题、第一作者姓氏和年份。L1 可直接查询 Crossref，L2 先审批实际元数据，L3 禁止联网。返回的 `verified`、`mismatch`、`uncertain` 或 `not-found` 只描述书目元数据；`claim_verification=manual_required` 表示仍须人工检查论文是否支持具体陈述。

## 等待、取消与失败

- 顶栏“任务中心”可查看资料上传、分析、外部资料导入、问答、研究辅助和轻量导出任务。
- 文件完成传输后可刷新查看任务；仍在传输时刷新，需要重新选择文件。
- 排队或运行中的本地任务可以请求停止；系统确认停止后才显示“已停止”，已经完成的步骤可能保留。
- 服务重启后的未完成本地任务会标为中断，需要手动重新发起。
- 外部请求一旦可能已经发出，不能保证撤回或安全重试；结果未知时请先核对，系统不会自动重发。
- 在线服务失败不会静默切换服务商。请根据提示检查配置或稍后手动重试。

## 修改、删除与撤销

- 在“数据管理”中查看历史版本、撤销最近变更和处理冲突。
- 删除资料会先移入回收站，**保留 30 天**，期间可以恢复。
- 到期后仍需再次确认才会永久删除；删除记录保留文件名。
- 恢复或撤销后，后续检索应与恢复后的有效资料一致。

## 轻量导出边界

“数据管理”支持创建和下载轻量导出文件，包含课题目录、当前资料信息和有效课题笔记，不含原件和历史版本。

**完整备份功能已移除，当前也不提供整库灾难恢复或换机恢复入口。**回收站中的单份资料恢复不受影响。

## 键盘与响应式

资料页签支持左右方向键、Home 和 End；任务结果和审批关闭后恢复焦点。已进行浏览器辅助功能结构与多种窗口宽度检查，但不宣称完成真实 VoiceOver、实体手机或完整移动科研验收。

## 停止服务

在启动终端按 `Ctrl+C`。资料仍保存在本机数据目录，下次启动后可继续使用。
