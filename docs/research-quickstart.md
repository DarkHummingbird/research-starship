# 科研星舰：普通用户使用说明

## 第一次使用

1. 运行 `./start_research.sh`；脚本会检查本地模型、向量化和文字识别组件。
2. 浏览器打开科研页面后，先点左上角“＋”新建课题。
3. 先上传一篇公开论文或虚构教程，熟悉流程。
4. 选择资料保密程度：
   - 公开资料：可使用已经启用的外部资料服务。
   - 内部资料：默认不发送给外部服务，发送前需要确认。
   - 保密资料：只在本机处理。
5. 上传后，系统会在本地分析。分析结果仍需要人工核对，不会自动进入正式知识库。

## 提问与核对

- 默认只使用当前课题已经确认的资料。
- “显示原文依据”适合直接查看来源；“本机生成回答”会组织回答，但仍需核对。
- 点击来源可查看引文，PDF 可打开实际页面。
- 找不到依据时，系统应明确说“未找到可核验证据”，不要强行补答。

## 文档切块方式

上传时默认使用“自动：父子 + 递归”：先按章节或页面保留父块，再按段落、句子和长度拆成较小的检索块。搜索使用子块，回答需要时可补充父块上下文；父块不会重复进入正式记忆。

高级选项还包括“仅递归切块”“固定长度（兜底）”和“语义切块（本地模型）”。语义切块使用本地 BGE-M3 判断相邻内容是否换题，不外发，也不让 LLM 自由编造切点；本地组件不可用时会停止。表格、公式和扫描页仍需人工核对。

如果切块不合适，目前需要重新上传为新资料并检查来源，不覆盖旧资料。不要只看切块数量，应通过实际问题和原文核对检索效果。

## 等待和失败

- 后台解析、文字识别和本地生成会争用本机资源；当前本地生成一次只运行一个任务，其他任务会排队。
- 排队不等于卡死。页面会显示等待、处理中和失败状态。
- 文件读取失败时，原件不会被改写；可以换文件或手动执行本地识别。
- 外部服务失败时，私有内容不会被自动重发。需要由你决定是否手动重试。

## 保存、修改和撤销

- 只有确认后的内容才进入正式科研记忆。
- 被拒绝的生成内容不能直接导出或归档，需要修改后重新校验。
- 资料支持历史版本、撤销、回收站和本地整库备份。
- 公式、表格和扫描页需要特别核对；OCR 置信度高也不代表公式符号一定正确。

## 备份与恢复边界

备份有两种方式：

- **轻量备份**：点击“轻量备份（不含原件）”，再点击“下载轻量备份”。JSON 文件只包含课题目录、当前资料信息和有效记忆，不包含原始文件、历史版本、模型原始输出或密钥，适合快速保存当前结果。
- **完整备份**：点击“完整备份（含可用原件）”，生成本地 ZIP，包含结构化数据和可用系统副本，并列出缺失文件。需要到本机 `RESEARCH_DATA_DIR/exports/<用户ID>/` 目录取文件。

**当前没有整库一键恢复入口**。无论 JSON 还是 ZIP，都不要仅因导出成功就认为恢复已经验证。恢复功能需要先完成独立验收；在此之前保留原始文件和数据库副本。

## 写作范围

局部写作功能目前处于暂缓优化状态。不要把生成内容直接用于正式投稿；引用、指标和实验陈述都需要人工核对。

## 停止服务

在启动终端按 `Ctrl+C`。资料仍保存在本机数据目录，下次启动后可继续使用。
